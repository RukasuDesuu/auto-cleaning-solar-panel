# Apresentações e Documentação Auxiliar

## Apresentação do CONICT 2026

`ASCM_CONICT_2026.pptx` é a apresentação de slides do trabalho para o 17º CONICT,
montada sobre o template oficial do evento (Câmpus Guarulhos, 24 a 26 de novembro
de 2026).

O conteúdo vem do resumo expandido em [`../Article/CONICT/main.tex`](../Article/CONICT/main.tex),
já na versão final que atende às correções do avaliador. As figuras são as mesmas
de [`../Article/images/`](../Article/images). Os slides de conteúdo trazem notas do
apresentador.

Ao atualizar o artigo, lembre-se de refletir as mudanças aqui: os dois arquivos não
são gerados a partir de uma fonte comum.
